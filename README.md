# AI Automation Projects

Business process automation projects built with n8n, running locally in Docker. All test data is invented.

- **00-shared:** workflows used by every project, such as the error handler.
- **01-client-onboarding:** a form-driven onboarding process with document tracking, daily reminders and escalation. (complete)
- **02-order-and-invoice-processing:** incoming orders validated, routed and logged. (planned)
- **03-customer-support-agent:** support requests classified, answered from documentation as drafts for approval, and logged. (planned)
